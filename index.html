Handwritten Digit Recognition on an FPGA

A small neural network written in VHDL, running on a Digilent Nexys 3 board (Xilinx Spartan-6). You draw a digit with the mouse on your PC, the image is sent to the FPGA over UART, and the board shows its answer.

  • Fully connected MLP, 64 → 32 (ReLU) → 10, with 2,410 parameters
  • 97.5% accuracy on 360 test images, the same before and after 8-bit quantization
  • Bit-exact: the VHDL gives exactly the same answer as the Python model on every test image
  • Classifies one image in 99 clock cycles (about 8 µs)
  • No IP cores: adders, multipliers and the UART are built from scratch, with no block RAM or DSP slices
Built with
  • VHDL
  • PyTorch
  • Python
  • Spartan-6 FPGA

16-bit Microprocessor on an FPGA

A simple accumulator-based microprocessor written in VHDL and implemented on a Digilent Nexys 3 board (Xilinx Spartan-6).

  • 16-bit data bus and 12-bit address bus (4,096 words of memory)

  • ALU with add, sub, and, or, xor, not and pass; accumulator with zero and sign flags
  • Runs a preloaded demo program, with output on the board's 7-segment display
