DOOM in the portfolio
=====================

doom.jsdos
  A zip containing the unmodified files from id Software's official
  DOOM v1.9 shareware release (doom19s.zip, idgames archive:
  idstuff/doom/doom19s.zip), plus two small config files:
    DEFAULT.CFG          sound card settings so audio works on first start
    .jsdos/dosbox.conf   DOSBox settings that launch DOOM.EXE
  DOOM1.WAD md5: f0cefca49926d00903cf57551d901abe (official v1.9 shareware)
  DOOM is (c) id Software. The shareware episode is freely distributable;
  see README.TXT and ORDER.FRM inside the bundle.
